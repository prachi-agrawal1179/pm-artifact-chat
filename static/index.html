    How it works

    1. Your files are parsed (Word, PDF, Excel, markdown, text).
    2. Text is split into overlapping chunks so retrieval stays specific.
    3. A local search index ranks the closest passages to your question.
    4. The answer is built only from those passages, with citations.
    5. Hugging Face runs semantic retrieval and summaries locally. OpenAI remains optional.

    Settings

    Optional. Without a key, answers stay extractive quotes from the closest chunks.
